- 系统使用的是：[ArchLinuxARM](http://archlinuxarm.org/platforms/armv6/raspberry-pi),下载地址：http://archlinuxarm.org/os/ArchLinuxARM-rpi-latest.tar.gz
- 如何超频： 

```
vi /boot/config.txt 
```

> 1. **armfreq**：ARM处理器的频率，单位是MHz。默认值是 700。
> 2. 最简单的方法是将txt文件最后的**armfreq**把前面的#去掉即可启用
> 3. ![树莓派超频配置](http://i2.tietuku.com/ebafff5ecdc9f144.jpg) 
> 4. 更加详细的配置可见：[英文原文](http://elinux.org/RPiconfig)|[中文翻译](http://www.shumeipai.net/forum.php?mod=viewthread&tid=19043&highlight=%CA%F7%DD%AE%C5%C9%C5%E4%D6%C3%CE%C4%B5%B5config.txt%CB%B5%C3%F7)。

- 如何查看当前CPU频率以及温度

> 1. 
>
>    查看频率
>
>    ```
>    cat /sys/class/thermal/thermal_zone0/temp
>    ```
>
> 2. 查看温度 
>
>    ```
>    cat /sys/devices/system/cpu/cpu0/cpufreq/scaling_cur_freq
>    ```
>
> 3. 显示结果如下图![树莓派温度以及频率显示](http://i2.tietuku.com/2a8e1de161392567.jpg)
>
> 4. 由图可知，当前CPU频率为**900**MHz，温度为**29**度。
