由于写博和整理资料的需要，一直用 HTML 来写东西。虽然可以用各种可视化的辅助工具来写，但是在键盘和鼠标之间频繁切换还是非常费事的。最近认真地学习了一下 Markdown，发现其实它非常易学易用。从下图就可以对比出 Markdown 是多么友好了，左边是 Markdown，右边是它对应的 HTML。
![img](20130309_Markdown%20%E5%B7%A5%E5%85%B7.assets/skitched-20120219-223731.jpg)



**Markdown 的优势**



Markdown 的理念是，能让文档更容易读、写和随意改。HTML 是一种发布的格式，Markdown 是一种书写的格式。就这样，Markdown 的格式语法只涵盖纯文本可以涵盖的范围。



你只需要学习几个简单的符号，然后专注于码字，文字的排版只是多打几个符号而已。想入门很简单，推荐专注于 Ubuntu/Linux 系统的博客[Wow! Ubuntu](https://web.archive.org/web/20131126023059/http://wowubuntu.com/) 的站长 @riku 整理的 Markdown 语法说明:[完整语法说](https://web.archive.org/web/20131126023059/http://wowubuntu.com/markdown/)明 和 [快速入门](https://web.archive.org/web/20131126023059/http://wowubuntu.com/markdown/basic.html)。



**Markdown 工具**



*Windows*：MarkdownPad，需要安装 Microsoft .NET Framework 4.0。



*Linux*：ReText，Ubuntu 安裝方法[参考这里](https://web.archive.org/web/20131126023059/http://antbsd.twbbs.org/~ant/wordpress/?p=3953)



*Mac*：Mou，或者 Sublime Text 2 。Mou – Markdown 语言编辑器 [Mac]。Sublime Text 2 – 非常强大的跨平台编辑器



*网页版*：[Dillinger](https://web.archive.org/web/20131126023059/http://dillinger.io/)via[Lucifr](https://web.archive.org/web/20131126023059/http://lucifr.com/2012/02/01/dillinger-online-markdown-editor/)



*GreaseMonkey 脚本*：Markdown textarea，此脚本会在文本域的左下角新增一个 Markdown 按钮，输入各种包含 Markdown 的文字之后，点击它就可以把代码转化为为 HTML。



**其他推荐**：



推荐1：Chrome 扩展 MaDe 左右分屏, 即写即出。



推荐2：Windows 下的 Markdown 软件： MEditor。



推荐3：用vim + [vimwiki](https://web.archive.org/web/20131126023059/http://xbeta.info/vimwiki.htm)，实乃神器。



推荐4：pandoc 可以在各种文档之间转换，html2markdown 没有问题。
