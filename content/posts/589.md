你的电脑如果能够正常浏览github.com和githubusercontent.com的话，那么采用官方的方法，使用如下命令即可安装ohmyzsh

`$ sh -c "$(curl -fsSL https://raw.github.com/ohmyzsh/ohmyzsh/master/tools/install.sh)"`
如果不是的话，那就建议使用gitee提供的国内镜像来安装，方法如下：

```bash
git clone https://gitee.com/mirrors/oh-my-zsh.git
cd oh-my-zsh/tools
vi ./install.sh
```
找到install.sh中的`REMOTE=${REMOTE:-https://github.com/${REPO}.git}`，将其修改为`REMOTE=${REMOTE:-https://gitee.com/mirrors/oh-my-zsh.git}`，保存即可。

然后执行`./install.sh`就可以使用国内镜像来正常安装ohmyzsh。
