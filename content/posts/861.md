本来想直接改源码的，后来发现使用的主题可以直接添加。

---

# 添加 自定义样式

![自定义css][1]

```css
body {
   /* Screen version */
   font-family: "LXGW WenKai Screen", sans-serif;
}
```

# 添加底部自定义内容
![webfont cdn地址][2]

## 饿了么CDN

```html
<link rel="stylesheet" href="https://npm.elemecdn.com/lxgw-wenkai-screen-webfont@1.7.0/style.css" media="print" onload="this.media='all'">
```

## 七牛云CDN

```html
<link rel="stylesheet" href="https://cdn.staticfile.org/lxgw-wenkai-screen-webfont/1.7.0/style.css" media="print" onload="this.media='all'">
```
