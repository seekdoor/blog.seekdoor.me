# 缘由

家里的电视是闲鱼350块钱买的老的46寸电视，是真的非常非常重，连玻璃底座预计会在40～50kg间。

之前在客厅的电视柜上是有一个大概35寸左右的电视机的，那个之前被我带回老家了。这个电视尺寸比之前的大很多，导致了电视放不进去，于是用了两个木椅子当底座。原来的电视柜现在被的放上了12u的机柜，里面存放着我的网络设备和NAS之类，有时间可以开坑讲解一下。

先是在pdd上面购买了一个`长120宽40高150cm`的四层货架，每层说是可以放40～60kg的东西，稍微对比了一下销量和评价就选了这一家。常州发货的，第二天就到了，取回家之后就开始了安装。

![订单截图][1]

# 货架规划和安装

![总体预览][2]

- 最下层板我距地面大概20cm左右，第一个空间的高度可以放下石头扫拖地机器人的充电桩和机器，平时也可以放体重计之类的。

![京东客服对话截图][3]

- 测量好电视底座的大概高度之后就可以放第二块层板了，这样第二个空间可以放平时客厅用到的杂物，我在上面放了Switch游戏《健身环大冒险》用的健身环+绑带、游戏手柄、joycon绑带等东西。

- 第三块层板就直接放到了最顶层，这样第三个空间就成型了，用来放电视。不得不说，这个电视实在是太重了，我费了九牛二虎之力才把它从之前的椅子上面挪到了架子上，挪的时候生怕把货架给蹭倒塌了。挪下去之后才发现玻璃底座下面有四个橡胶突起，感觉时间长了会在层板上面留下四个印记，于是又费了大力在电视底座下面垫了一块木板。

- 第四块层板我放到了第三个空间也就是电视机的后面，用作挡板。
 - 一是因为这个货架毕竟不是重型货架，铁皮还是有点软的，加上电视太重，怕到时候受力不均匀倒了；
 - 二是因为家里有猫，老三绝育后依旧是很调皮，经常喜欢爬到电视机上面，然后再爬到其他地方，幸好电视机重，不然电视估计早就香消玉殒了；
 - 三是因为总长度是1.2m，再加上材质较软的原因，用手晃的话其实还是会动的，加在后面的话也能有个力支撑。

# 其他

- 初次安装的时候一定要数角铁上的空格做标记，不要大概的比对尺寸。我安装完后发现最下面一层一侧矮了一点，重新安装的。想放电视的时候又发现第二层也是歪的，简直要吐血。
- 螺丝和螺帽上有油，很难洗（不要问我为什么知道），装的时候建议带劳保手套。
- Switch和移动机顶盒是用2入1出的HDMI分线器连接到电视机的HDMI接口上的，虽然这个电视后面有两个HDMI接口，但是买时候因为是老电视，没有遥控器（淘宝买了一个也没用），切换HDMI输入的时候要操作顶部的按钮，现在因为电视机顶部和货架最上层的层板举例太近了，实在是不方便，就用这个替代了，按一下就能切换。
