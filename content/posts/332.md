#破解方法：
1.在hosts文件中加入`0.0.0.0 store.esellerate.net`
hosts文件 `C:\Windows\System32\drivers\etc\hosts`

2.打开Scrivener，它会弹出激活提示，点"Enter Key"，用注册机生成一个serial填上。

3.提示激活失败后，点击cancel。

4.选择"Activate using a different computer that has web access" 然后点击 "Next"。
复制生成的id，点击"Back"，粘贴到注册机中Activation下的“Paste Activation Key here"处，点击Active.

5.选择"I already have an ACtivation Key and would like to activate now"，
粘贴刚刚Active得到的activation key，"Done"。
