# 自部署

## 下载项目代码
- `git clone https://github.com/Zeyi-Lin/HivisionIDPhotos.git`

## 安装Python环境miniconda

- `Windows Command Prompt`方式
```bash
curl https://repo.anaconda.com/miniconda/Miniconda3-latest-Windows-x86_64.exe -o miniconda.exe
start /wait "" .\miniconda.exe /S
del miniconda.exe
```
- `Windows PowerShell`方式
```powershell
curl https://repo.anaconda.com/miniconda/Miniconda3-latest-Windows-x86_64.exe -o miniconda.exe
Start-Process -FilePath ".\miniconda.exe" -ArgumentList "/S" -Wait
del miniconda.exe
```

## 生成激活虚拟环境
- 进入`HivisionIDPhotos`目录，打开该目录下的`cmd`
- `conda create -n photo python=3.10`
- `conda init`
- `conda activate photo`

## 安装依赖
- `pip install -r requirements.txt`
- `pip install -r requirements-app.txt`

## 下载人像抠图模型权重文件

### 方式一：脚本下载

```bash
python scripts/download_model.py --models all
# 如需指定下载某个模型
# python scripts/download_model.py --models modnet_photographic_portrait_matting
```

### 方式二：直接下载

如果下载网速不顺利：前往[SwanHub][1]下载。

人像抠图模型模型均存到项目的`hivision/creator/weights`目录下：
- MODNet MODNet官方权重
 - https://github.com/Zeyi-Lin/HivisionIDPhotos/releases/download/pretrained-model/modnet_photographic_portrait_matting.onnx
- hivision_modnet 对纯色换底适配性更好的抠图模型
 - https://github.com/Zeyi-Lin/HivisionIDPhotos/releases/download/pretrained-model/hivision_modnet.onnx
- rmbg-1.4 BRIA AI 开源的抠图模型
 - https://huggingface.co/briaai/RMBG-1.4/resolve/main/onnx/model.onnx?download=true
 - 重命名为`rmbg-1.4.onnx`
- birefnet-v1-lite ZhengPeng7 开源的抠图模型，拥有最好的分割精度
 - https://github.com/ZhengPeng7/BiRefNet/releases/download/v1/BiRefNet-general-bb_swin_v1_tiny-epoch_232.onnx
 - 重命名为`birefnet-v1-lite.onnx`

人脸检测模型配置（可选）
- MTCNN	离线人脸检测模型，高性能CPU推理（毫秒级），为默认模型，检测精度较低	
 - Clone此项目后直接使用
- RetinaFace 离线人脸检测模型，CPU推理速度中等（秒级），精度较高
 - [下载][2]后放到`hivision/creator/retinaface/weights`目录下
- Face++ 旷视推出的在线人脸检测API，检测精度较高 [官方文档][3]
 - [使用文档][4]

## 运行 Gradio Demo

- `python app.py`
 - 运行程序将生成一个本地 Web 页面，在页面中可完成证件照的操作与交互。
- 在你的本地访问 http://127.0.0.1:7860 即可使用。
