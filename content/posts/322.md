- `ctrl+alt+t` 调出命令行终端，接着输入
```bash
sudo vim /boot/grub/grub.cfg
```
- 找到 `set gfxmode=auto` 将其改为 `set gfxmode=800x600` 
然后重启即可

- 如果系统没有安装Vim的话，就先运行下面的命令，再执行上边的操作
```bash
sudo apt-get install vim
```
