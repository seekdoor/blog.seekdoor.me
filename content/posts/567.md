有时候会遇到软件厂商或者作用只提供了 deb 格式的软件安装包，但还需要额外是依赖库才能正常运行。

直接使用命令 `dpkg -i *.deb` ，是不能处理 deb 里定义的依赖关系的。

正确做法是使用 apt 安装 deb 文件：

```bash
sudo apt-get --fix-broken install *.deb
```

这样可以自动处理依赖关系。
