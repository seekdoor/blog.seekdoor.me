# 获取 Deeplx API key

- 参考: [分享几个Deeplx代理地址 - LINUX DO](https://linux.do/t/topic/39205/38)
- 我用的[是始皇提供的服务][1]

> 前几天我的 deeplx 被一个老六开着代理日刷百万次，我直接放弃更新。不过看很多佬友期待的眼神，还是给它复活了。
> 现在我为它加了 LINUX DO Connect 认证，用以杜绝被刷。最新的接口地址是：
> `https://api.deeplx.org/<api-key>/translate`
> 每个人的地址都是不同的，这个 <api-key> 请去 https://connect.linux.do 获取，就是那一串 DeepLX Api Key 的字符串 。

# 安装油猴脚本

`https://download.immersivetranslate.com/immersive-translate.user.js`

# 配置

- 打开沉浸式翻译[设置页][2]

- 切换到 “开发者设置”，开启 Beta 测试特性
![打开沉浸式翻译设置页01_20250411.0947.jpg][3]

- 翻译服务选择Deeplx
![02_20250411.0949.jpg][4]

- 填写 API URL `https://api.deeplx.org/translate`

- 展开自定义选项，调整配置
![03_20250411.0951.jpg][5]

# 注意事项

- 如果是油猴脚本方式安装的，需要编辑脚本设置添加域名白名单 `api.deeplx.org`
![04_20250411.0952.jpg][6]
