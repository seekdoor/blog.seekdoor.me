# 缘由

偶然想起来在以前的旧博客上是在侧边栏上有 图像榜单 的，但是因为以前的博客数据丢失了，就一直没找到怎么添加。

前一段时间在七牛云中找回了以前博客的部分数据，在 自定义主题 里面找到了这个代码。在 Bangumi 网站上修改个人信息的时候意外的发现了地址，现在记录下来防止以后忘了。

# 使用

## 地址
http://bgm.tv/settings/img_chart

## 选择样式
![选择样式][1]

## 如何使用
**演示的是我自己的代码**，请自行替换。
- 在右侧选择 HTML 代码并复制用于Blog、个人网站等支持HTML的地方
```html
<a href="http://bgm.tv/user/pcwuyu"><img src="http://bgm.tv/chart/img/184601" border="0" alt="袅残烟 的个人主页" /></a>
```
- 在右侧选择 BBCODE 代码并复制(用于允许使用img代码的论坛)
```html
[url=http://bgm.tv/user/pcwuyu][img]http://bgm.tv/chart/img/184601[/img][/url]
```
# 注意事项
图片榜单保存在本地服务器上，显示的条目可能有所延迟，请保持冷静。
