[Sublime Text 3](http://www.sublimetext.com/3) is currently in beta. The latest build is 3059. We are going to install Sublime Text 3 build 3059 from AUR, from AUR.

[![Sublime_text_3_manjaro](https://1102047360.rsc.cdn77.org/wp-content/uploads/2014/05/Sublime_text_3_manjaro.png)](https://www.unixmen.com/wp-content/uploads/2014/05/Sublime_text_3_manjaro.png)

Open terminal and run the command below, follow the Y/N questions to continue.

```
sudo yaourt -S sublime-text-dev
```
